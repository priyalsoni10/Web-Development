CSS stands for Cascading Style Sheets. It is used to style and layout web pages. For example, you can use CSS to change the font, color, size and spacing of your content, split it into multiple columns, or add animations and other decorative features.

Why use CSS?

CSS is used to control the style of a web document in a simple and easy way. CSS is the acronym for "Cascading Style Sheets". This tutorial will teach you basic CSS concepts and how to use CSS to style your HTML pages.

CSS saves a lot of work. It can control the layout of multiple web pages all at once. External stylesheets are stored in CSS files.
